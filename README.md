
# Student Management System

## Project Purpose
The Student Management System is a simple web application developed to manage student records. It allows users to view, add, search, update, and delete student information.

## Technologies
- Programming Language: Python 3.10
- Framework: Flask
- Testing Framework: pytest
- Code Coverage: pytest-cov
- IDE: Visual Studio Code
- Static Code Analysis: SonarQube Cloud
- CI/CD: GitHub Actions

## Baseline Version
Version: 1.0 - Initial Baseline

The initial version contains the original application code and automated tests before any code quality improvements. This version will be used for the baseline SonarQube Cloud analysis.

## Running the Application

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python app.py
```

## Running Tests

```bash
python -m pytest -v
```
